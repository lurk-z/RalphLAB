# Tam · ทดสอบ RalphLAB จากแชต LINE บนมือถือ

บอตจะตอบด้วยใบงานตัวอย่าง `WO-001` ที่สร้างตอนเปิดเซิร์ฟเวอร์ ใช้คำสั่ง `สรุปวันนี้` หรือ `ดูเคส WO-001` ได้จากแอป LINE ข้อมูลใบงานที่แก้ในเดโม HTML เก็บแยกในเบราว์เซอร์

1. เปิด LINE Developers Console เลือก provider และ Messaging API channel ของบัญชีทดสอบ ใน **Basic settings → Channel secret** ใช้ค่าใหม่หากค่าเดิมถูกเปิดเผย ใน **Messaging API → Channel access token** กด **Issue** เพื่อรับ token เก็บทั้งสองค่าไว้ใช้บนเครื่องที่รันบอต
2. ดาวน์โหลด [ZIP ของสาขา Tam](https://github.com/lurk-z/RalphLAB/archive/refs/heads/feature/tam-line-telegram-demo.zip) แล้วแตกไฟล์ทั้งโฟลเดอร์ หรือใช้ checkout ของสาขานี้ บน Windows ที่มี Node.js 20 ขึ้นไป เปิด `integrations\line-demo\start.cmd` แล้วกรอกสองค่าในหน้าต่างที่เปิดขึ้น โปรแกรมซ่อนค่าที่พิมพ์และใช้เฉพาะระหว่างที่เซิร์ฟเวอร์ทำงาน เปิดหน้าต่างนี้ค้างไว้
3. เปิด PowerShell อีกหน้าต่างหนึ่ง หากยังไม่มี cloudflared ให้ติดตั้งด้วย `winget install --id Cloudflare.cloudflared --exact` แล้วเปิด PowerShell ใหม่ รัน `cloudflared tunnel --url http://127.0.0.1:8787` และเปิดหน้าต่างนี้ค้างไว้
4. คัดลอก URL ที่ลงท้ายด้วย `.trycloudflare.com` จากหน้าต่างที่สอง เติม `/line/webhook` แล้ววางใน **Messaging API → Webhook URL** กด **Verify** ให้ขึ้น **Success** แล้วเปิด **Use webhook** เมื่อเปิด tunnel ใหม่ให้ใช้ URL ใหม่
5. สแกน QR code ในแท็บ Messaging API เพื่อเพิ่ม OA เป็นเพื่อน ส่ง `ดูเคส WO-001` ใน LINE ควรได้รับคำตอบที่ขึ้นต้นด้วย **RalphLAB · ข้อมูลสาธิต** และมีสถานะ **รอหัวหน้าอนุมัติ**

ทดสอบ webhook ในเครื่องโดยใช้ token จำลองได้ด้วย `node --test integrations/line-demo/server.test.mjs` จากโฟลเดอร์หลักของ repo

[คู่มือ LINE](https://developers.line.biz/en/docs/messaging-api/building-bot/) · [คู่มือ Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)

## Tam · แจ้งเตือนและสั่งงานใบงานติดตามตามเวลาของก็อต

1. เปิด [ใบงานติดตามตามเวลา](https://ralphlab-workbench.surawit2003it.chatgpt.site/lab-room/timed) ด้วยบัญชีเจ้าของ เลือกใบงานทดสอบหรือสร้างใบใหม่โดยตั้งชื่อขึ้นต้นด้วย **Tam** เมื่อเปิดใบงานเฉพาะใบแล้ว URL จะมี `?id=...` กด **เชื่อมใบงานกับ LINE ของทีม → ออกรหัสเชื่อมต่อใหม่** บนใบงานทดสอบ เก็บรหัสบนเครื่อง การออกใหม่จะแทนรหัสเดิมของใบนั้น
2. ผู้รันบอตเตรียม secret/token ของ OA จากที่เก็บรหัสของทีม สำหรับ Site สาธารณะให้กด Enter ข้ามช่อง Site service token ส่วน Site ส่วนตัวให้ใช้ service access token ของ Site นั้นจากผู้ดูแล หากเคยเปิดเผยค่าในการทดสอบ ให้เปลี่ยนก่อนใช้กับข้อมูลของทีม
3. เปิด ZIP หรือ checkout ล่าสุดของสาขา Tam หยุดเซิร์ฟเวอร์ตัวอย่างในหน้าต่าง `start.cmd` ด้วย Ctrl+C แล้วเปิด `integrations\line-demo\start-study.cmd` บนเครื่องที่มี Node.js 22 ขึ้นไป กรอก URL ใบงานและค่าลับในหน้าต่างนั้น ใช้พอร์ต 8787 และ tunnel เดิมได้ ทั้งหน้าต่างตัวเชื่อมและ tunnel ต้องเปิดค้างไว้
4. จับคู่แบบเจอตัว: เจ้าของใบงานให้ผู้รับที่เลือกพิมพ์คำสั่ง **จับคู่ …** ที่หน้าต่างเพิ่งแสดง ลงในแชตส่วนตัวกับ OA ภายใน 10 นาที ผู้ที่มีรหัสสามารถรับสิทธิ์ต่อใบงานนี้ได้ เก็บรหัสให้เห็นเฉพาะผู้รับ เมื่อได้รับการยืนยันให้ส่ง **ดูเคส** ตรวจว่าชื่อและสถานะตรงกับหน้าใบงาน คำสั่ง **สรุปวันนี้** แสดงความเคลื่อนไหวของใบที่ผูกไว้ตามเวลาไทย รอบวัดถึงกำหนด ใบงานพัก และรายงานท้ายงานจะส่งให้ผู้รับอัตโนมัติ โดยตรวจทุก 30 วินาที
5. ใช้ใบงานทดสอบรายงานปัญหาเครื่องวัดจากหน้าเว็บ รอข้อความ LINE แล้วตอบโดยใช้เลขรุ่นที่บอตส่งจริง เช่น `เพิ่ม 3 0.02 ตรวจสีซ้ำหลังปรับเครื่อง` (เพิ่มรอบในอีก 1.2 นาที), `ต่อ 3 ตรวจเครื่องแล้ว` หรือ `หยุด 3 ยุติการทดสอบ` ใบงานที่รับคำสั่งแล้วจะแจ้งการตัดสินใจในข้อความอัปเดต ตรวจว่าคำสั่งซ้ำเปลี่ยนงานเพียงครั้งเดียว แชตกลุ่มและ LINE ID อื่นต้องดูหรือแก้ใบงานนี้ไม่ได้
6. หากเลือกเพิ่มรอบ ให้บันทึกผลทดสอบที่สังเกตได้บนเว็บเมื่อถึงกำหนด จนครบทุกรอบ แล้วตรวจว่ามีสรุปจบงานใน LINE หากเลือกหยุด ข้อความจะแจ้ง **ปิดงานตามคำสั่ง** หากขึ้น RalphLAB 401/403 ให้ตรวจ service token และรหัสของใบงานนั้นกับเจ้าของ

ตัวเชื่อมนี้ต่อกับ relay ของสาขา GOD การเข้าใช้ Site และการมอบหมายผู้รับยังอยู่ในการควบคุมของเจ้าของ ระบบผูกบัญชีด้วยตนเองสำหรับผู้ใช้หลายคนเป็นงานอีกขั้น ดู [ที่มาของตัวเชื่อม](https://github.com/lurk-z/RalphLAB/blob/db7e7234411203ef63dad08aeec7ba3dc24719fd/integrations/timed-studies/integrations/timed-line.mjs)

ทดสอบทั้งโหมดตัวอย่างและโหมดใบงานที่ผูกไว้ด้วย `node --test integrations/line-demo/server.test.mjs integrations/line-demo/study.test.mjs`

### Tam · เดโมรอบแรกบนโน้ตบุ๊กก็อต

- ถ้าเครื่อง Tam รันตัวเชื่อมใบงานและ tunnel อยู่แล้ว ก็อตเปิด LINE บนโน้ตบุ๊ก เพิ่มเพื่อน OA แล้วส่งรหัสจับคู่ส่วนตัวหนึ่งครั้งก่อนฉายหน้าจอ เครื่องที่เปิด LINE กับเครื่องที่รันตัวเชื่อมแยกกันได้
- ถ้าจะรันทุกอย่างบนโน้ตบุ๊กก็อต ให้ดาวน์โหลดสาขาล่าสุด ติดตั้ง Node.js 22+ และ cloudflared เปิดตัวเชื่อมกับ tunnel บนเครื่องก็อต ตั้ง webhook ของ OA ไปยัง URL ใหม่ที่ลงท้ายด้วย `/line/webhook` แล้วกด Verify ระหว่างเดโมให้มีตัวเชื่อมที่ส่งแจ้งเตือนเพียงตัวเดียวสำหรับใบงานนั้น
- รหัสผูกหนึ่ง LINE กับหนึ่งใบงานตลอดการรันครั้งนี้ รีสตาร์ตตัวเชื่อมเพื่อยกเลิกและจับคู่ใหม่ ทดสอบด้วยใบงานตัวอย่างที่เจ้าของอนุญาต
