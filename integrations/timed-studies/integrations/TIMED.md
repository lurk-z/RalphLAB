# งานติดตามตามเวลา

คลังอ้างอิงในใบงานรองรับไฟล์ PDF, TXT, MD, CSV และ JSON ขนาดไม่เกิน 10 MiB ต่อไฟล์ เจ้าของระบุบทบาท Agent หน้าเอกสารหรือแถวข้อมูล และเหตุผลที่ใช้ ตัวเว็บเก็บต้นฉบับใน R2 ผ่าน binding `BUCKET` และเก็บรายการอ้างอิงใน D1 ผ่าน `DB` ไฟล์ข้อความมีตัวอย่าง 600 อักขระแรก ส่วน PDF ใช้หน้าที่ระบุและบันทึกของผู้ใช้ งานวิจัยและซอฟต์แวร์ที่เลือกใช้จากผลค้นมีบัตรอ้างอิง JSON ให้ดาวน์โหลด

เปิด /lab-room/timed ใน Site แล้วกรอกโจทย์ เป้าหมาย เงื่อนไข ตัวชี้วัด หน่วย และเวลาที่ต้องการสังเกต ระบบเก็บเวลาจริง หลักฐาน และรายงานแยกตามบัญชี การบันทึกค่าที่เกินเกณฑ์หรือการระบุปัญหาจะพักงานจนเจ้าของเลือกติดตามต่อ เพิ่มรอบ หรือยุติ

## ตัวเชื่อม LINE สำหรับใบงาน

ตัวเชื่อมหนึ่ง instance ดูแลหนึ่งใบงานและหนึ่งผู้ใช้ LINE สนทนาโดยตรงกับ LINE Official Account ของทีม เปิดเมนูเชื่อมต่อในใบงานแล้วเก็บรหัสเป็น RALPHLAB_STUDY_KEY ตั้ง RALPHLAB_STUDY_ID จาก id ในลิงก์ และ RALPHLAB_SITE_URL เป็น origin ของ Site ส่วน Site ส่วนตัวต้องใส่ RALPHLAB_SITES_TOKEN สำหรับ service access

ตั้ง LINE_CHANNEL_SECRET, LINE_CHANNEL_ACCESS_TOKEN และ LINE_USER_ID ใน secret store ของเครื่องที่รัน Node.js 22+ แล้วรัน `node timed-line.mjs` นำ HTTPS reverse proxy ของทีมมายังพอร์ต 8788 ตั้ง webhook ใน LINE Developers เป็น /line/webhook และเปิด Use webhook ผู้รับต้องเพิ่ม OA เป็นเพื่อน ใช้ช่องทดสอบแยกจาก webhook ที่ทีมใช้งานจริง เมื่อตั้งค่าเรียบร้อย ตัวเชื่อมตรวจรอบทุก 30 วินาทีแม้ปิดเว็บ เมื่อได้รับแจ้งปัญหา ให้ตอบตามตัวอย่างในข้อความพร้อมหมายเลขรุ่นของใบงานและเหตุผล การออกรหัสใหม่แทนรหัสเดิมทันที

กำหนดการเป็นเวลานัดรับข้อมูล ผู้ใช้ต้องกรอกผลจากการวัดจริงและหลักฐาน ระบบคำนวณผลต่างจากค่าที่บันทึกและไม่สรุปความปลอดภัยหรือการระคายเคืองจากระยะเวลาเพียงอย่างเดียว
